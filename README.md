# Playbook Pro

Rugby playbook platform for coaches and players. Animated play designer with canvas-based rendering, team publishing, and magic-link authentication.

**Stack:** React 19, TypeScript, Vite, Supabase, Konva.js, Tailwind CSS

## Features
- Canvas-based play designer with drag-and-drop player positioning
- Animated play diagrams with movement paths and timing
- Team management with shared playbooks
- Magic-link authentication (no passwords)
- Public play library for browsing

## Getting Started
```bash
npm install
npm run dev
```
